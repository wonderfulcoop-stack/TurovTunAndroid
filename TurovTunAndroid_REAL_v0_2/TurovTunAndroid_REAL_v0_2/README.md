# TurovTun Android REAL v0.2

Это сборщик настоящего Android VPN-клиента TurovTun на базе официального sing-box/SFA.

## Что получится

После сборки GitHub Actions выдаст APK, который умеет работать как настоящий VPN-клиент:

- запуск через Android VPNService / TUN;
- импорт локальных и remote/subscription конфигов;
- поддержка sing-box core;
- VLESS / Reality через sing-box;
- не привязан к твоему серверу — пользователь вставляет свою ссылку или подписку.

## Почему так

Писать VPNService с нуля долго и рискованно. Поэтому эта версия берёт официальный исходник sing-box Android, собирает `libbox.aar`, патчит название/брендинг под TurovTun и собирает APK.

## Как собрать APK через GitHub

1. Создай новый репозиторий на GitHub.
2. Загрузи все файлы из этого ZIP в корень репозитория.
3. Открой вкладку **Actions**.
4. Запусти workflow **Build TurovTun REAL VPN APK**.
5. После завершения скачай artifact **TurovTun-real-apk**.

## Как использовать APK

1. Установи APK на телефон.
2. Открой TurovTun.
3. Добавь профиль/конфиг:
   - прямой `vless://...`, если UI позволяет прямой импорт;
   - либо subscription URL;
   - либо sing-box JSON.
4. Нажми старт.
5. Android спросит разрешение на VPN — разреши.

## Важно

Это не прошлый конфигуратор v0.1. Эта сборка использует реальный sing-box Android core и TUN-режим. Если GitHub сборка упадёт из-за изменений в upstream sing-box, открой лог Actions и смотри шаг `Build real APK`; там будет конкретная ошибка.

## Лицензия

Upstream sing-box/SFA распространяется под GPL-3.0-or-later. Этот сборщик не содержит исходники sing-box внутри ZIP, но при сборке клонирует официальный репозиторий и применяет брендинг. Не называй приложение `sing-box` и не выдавай его за официальный клиент.
