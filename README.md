# TurovTun Android — REAL VPN build

Это репозиторий-сборщик настоящего Android APK для TurovTun.

Что он делает:

1. GitHub Actions скачивает официальный исходник sing-box с Android-клиентом.
2. Собирает `libbox.aar` — реальное VPN/proxy-ядро.
3. Вставляет бренд TurovTun: название, package id, иконку и ассеты из ПК-версии.
4. Собирает APK, который реально запускает Android VPN через движок sing-box/SFA.

## Как собрать APK

1. Создай новый GitHub репозиторий.
2. Загрузи в корень все файлы из этой папки:
   - `.github`
   - `scripts`
   - `branding`
   - `docs`
   - `README.md`
3. Открой вкладку **Actions**.
4. Запусти workflow **Build TurovTun Android REAL APK**.
5. После зелёной сборки скачай artifact **TurovTun-real-working-apk**.
6. Внутри будет APK. Установи его на Android.

## Как добавить свою подписку

После установки открой TurovTun и добавь свой профиль/remote config/subscription как в sing-box/SFA:

- `vless://...`
- remote URL подписки
- sing-box JSON config

## Важно

Это уже не пустой конфигуратор. APK собирается с настоящим `libbox.aar` и Android-клиентом sing-box. Поэтому подключение работает через реальный Android VPN, а не через фейковую кнопку.

Интерфейс внутри базируется на реальном Android-клиенте sing-box, но бренд, название и иконки TurovTun вшиваются автоматически. Ассеты из ПК-версии положены в `assets/turovtun`, чтобы дальше можно было поверх этого делать полностью кастомный экран.

## Если сборка упала

Открой красный запуск Actions → последний красный шаг → скопируй лог ошибки. Обычно проблема бывает из-за изменения структуры официального sing-box репозитория или временной ошибки загрузки зависимостей.
